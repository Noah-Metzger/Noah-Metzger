# Noah Metzger

> Data engineer & scientist working at the intersection of **climate**, **AI**, and things worth building.

---

### About

3+ years shipping production data systems — pipelines, models, and the infra underneath.
Currently at **Project Canary**, building ingestion and analytics infra for methane emissions monitoring — turning raw sensor, telemetry, and geospatial data into products that push the industry toward measurable climate accountability.

### Currently

- Exploring **local AI models on proprietary data** — open-weight LLMs and agents on self-owned datasets, not someone else's API
- Building a personal streaming market-data platform (Kafka → TimescaleDB → FastAPI → Next.js) as the substrate for those experiments
- Open to collabs on ambitious technical work

### Featured

- **Paper** — [*A Framework for Optimizing Continuous Methane Monitoring System Configuration for Minimal Blind Time*](https://doi.org/10.1021/acsestair.4c00280) *(ACS ES&T Air)* — sensor-placement optimization applied across 100+ operational oil & gas facilities.
